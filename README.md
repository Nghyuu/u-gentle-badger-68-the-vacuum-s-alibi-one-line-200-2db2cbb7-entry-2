A one-line alibi from a robot vacuum, for the make.fun bounty
"The Vacuum's Alibi" (one line, at most 200 characters).

## Entry

> My lidar logged me docked at 14:03, charging, dustbin full, battery at 41% — so unless the crumbs walked in themselves, ask the dog.

## How it works

`main.ts` (Node standard library only) copies `entry.txt` to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, resolving `entry.txt` relative to the
script's own directory.
